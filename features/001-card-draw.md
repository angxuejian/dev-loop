# Feature: 卡牌抽卡系统

## Description

实现一个简单的卡牌抽卡页面，让用户通过抽卡获得不同稀有度的卡牌，并查看抽卡结果和保底进度。使用原生 TypeScript、HTML 和 CSS，不使用前端框架，功能文件集中放在 `frontend/card-draw/` 中。

## Scope

- 提供可在浏览器运行的页面和明确的本地启动方式，沿用仓库现有开发约定，仅添加运行本功能必需的配置。
- 内置简单卡池，包含 R、SR、SSR 三种稀有度，每种至少一张卡牌；卡牌显示名称和稀有度，使用文字和样式即可，不要求图片素材或复杂动画。
- 提供单次抽卡按钮，每次点击获得一张卡牌，并在页面显示本次结果；同一卡牌允许重复抽取。
- 未触发保底时，每次抽卡的稀有度概率为 R 80%、SR 18%、SSR 2%；同一稀有度有多张卡牌时，等概率抽取其中一张。
- 使用固定保底规则：连续 49 次未抽到 SSR 后，第 50 次必定获得 SSR；任何一次抽到 SSR 都将连续未出 SSR 的计数重置为 0，抽到 R 或 SR 时计数增加 1。
- 页面展示三种稀有度的基础概率、保底规则及当前连续未出 SSR 的次数；初始计数为 0。
- 保持纯前端、单页面和当前页面会话内的简单交互，刷新页面后恢复初始状态。不包含后端、账号、付费、十连抽、收藏管理或历史记录功能。

## Acceptance Criteria

- [ ] 按提供的本地启动说明可以打开抽卡页面；功能代码位于 `frontend/card-draw/`，使用 TypeScript 且不依赖前端框架。
- [ ] 初次打开页面可以看到抽卡按钮、R 80% / SR 18% / SSR 2% 的基础概率、50 抽保底规则和初始为 0 的保底计数。
- [ ] 点击一次抽卡按钮恰好获得一张内置卡池中的卡牌，页面显示其名称和稀有度；连续点击能够继续抽卡并更新结果。
- [ ] 卡池包含 R、SR、SSR 三种稀有度；结果通过文字明确标识稀有度，并以不同样式区分。
- [ ] 在未触发保底的情况下，通过可控随机输入验证稀有度选择对应 80%、18%、2% 的概率区间，区间边界无遗漏或重叠；同稀有度存在多张卡牌时均有相等的被选中机会。
- [ ] 连续 49 次获得 R 或 SR 后，页面计数为 49，下一次抽卡无论随机输入如何都获得 SSR，并将计数重置为 0。
- [ ] 在保底触发前抽到 SSR 也会将计数重置为 0；随后抽到 R 或 SR 时从 1 重新累计，且 SR 不会重置计数。
- [ ] 每次抽卡后，页面结果和保底计数与本次抽卡行为一致；刷新页面后计数恢复为 0，抽卡结果恢复初始状态。
- [ ] 仓库要求的 lint、格式化及类型检查通过。
